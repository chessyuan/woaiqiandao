# 我爱签到 (WoAiQianDao) — Android 课程签到与任务管理工具

> **当前状态**：公开 Beta 内测中 (3 天体验版)

《我爱签到》（WoAiQianDao）是基于开源项目 [ChaoxingSignFaker](https://github.com/aquamarine5/ChaoxingSignFaker)（作者：aquamarine5 及其贡献者，遵循 AGPLv3 协议）定制的 Android 课程管理与签到交互优化工具。

## 📦 下载与安装

请前往 [Releases 页面](https://github.com/chessyuan/woaiqiandao/releases) 下载最新 Beta 版安装包。

- **最新版本**：`v0.3-beta` (3 天体验版 · 同步 R5.5.16 核心特性)

- **文件大小**：26,742,242 字节 (约 25.50 MiB)
- **SHA-256**：`9A09F27A8058692DE8E48093151CCE4E601D9507DCD7DCB655DA4D8468ED0A50`

### v0.3-beta 新特性说明

1. **免责声明确认机制**：首次使用需明确知悉免责与合规须知；
2. **历史签到统计与排行榜**：支持单门课程全部历史签到活动浏览与本学期签到汇总；
3. **学期课程发现与候选替换**：自动扫描 9 月以来的签到活动并提取候选课程，支持班级智能替换；
4. **深度无损瘦身优化**：安装包体积从原 40.94 MiB 缩减至 25.50 MiB（降幅约 38%）；
5. **升级兼容性**：保留原 RSA-3072 私有签名与包名，支持旧版覆盖升级，不重置试用有效期。
